# Alaska 2028

A complete static travel website built for GitHub and Vercel.

The main page includes a focused 13-day late-May 2028 itinerary, checked per-person planning costs, an interactive ฿220,000 savings target, and a device-local Trip Ideas board.

## Deploy

Upload everything in this folder to the root of a GitHub repository, then import that repository into Vercel. No build command or environment variables are required.

All photographs are stored in `assets/images`, so the deployed site does not depend on remote image links.

The Trip Ideas board uses browser storage. Ideas remain on the device and browser where they were added; no account or database is required.
